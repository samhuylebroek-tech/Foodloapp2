# Project Memory

## Core
App = "Foodlo" (voorlopige naam; eerder MaJeBa / Shared Kitchen / Samen Koken) — naam kan nog wijzigen, hou hem makkelijk aanpasbaar.
Installeerbare web-app (PWA) via link of QR-code — bewust NIET in App Store/Play Store.
Logo: strakke groene kookpot met hart-stoom in sage/emerald (src/assets/logo.png). Geen "lovable" in deellinks — eigen domein gewenst.
Alle teksten in het Nederlands; ontwerp voor 20-jarigen én 70+: grote knoppen (min. 56px), grote tekst, weinig stappen.
Standaard stijl: strakke sage & slate — lichtgrijze achtergrond, witte kaarten, emerald primair, Inter font; oud warm thema is nog beschikbaar in instellingen.
